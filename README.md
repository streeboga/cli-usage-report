# CLI usage report — Claude Code + Codex

Локальный сборщик токенов по **всем моделям за выбранный период**. Python 3.9+, только стандартная библиотека, без установки зависимостей и сетевых запросов.

```bash
git clone https://github.com/streeboga/cli-usage-report.git
cd cli-usage-report
python3 collect-cli-usage.py --from 2026-09-26 --to 2026-10-02 --timezone Europe/Moscow --output reports/usage.json
```

Обе даты включены. Берётся время события потребления в указанном часовом поясе, а не дата создания файла. Последние семь полных дней — семь дней до сегодняшнего дня включительно по вчерашний день.

По умолчанию читает `~/.claude/projects/**/*.jsonl`, `$CODEX_HOME/sessions/**/*.jsonl` и `$CODEX_HOME/archived_sessions/**/*.jsonl` (если CODEX_HOME не задан, `~/.codex`). Вложенные журналы подагентов включены. Можно указать свои директории:

```bash
python3 collect-cli-usage.py --from 2026-09-26 --to 2026-10-02 --claude-dir /path/to/projects --codex-dir /path/to/codex --output reports/usage.json
```

Результат записывается в JSON с правами `0600` и печатается в stdout. В нём период, количество проверенных файлов и по каждой паре источник/модель:

- `input`: вход без прочитанного кэша;
- `output`: выход, включая reasoning Codex без повторного добавления;
- `cache_read`, `cache_write_5m`, `cache_write_1h`: отдельные корзины;
- `responses`: количество учтённых событий с финальным usage.

Claude: повторные записи и форки сводятся по `message.id`, используется финальный usage. Запись кэша разделяется по `ephemeral_5m_input_tokens` / `ephemeral_1h_input_tokens`; старый формат использует общий счётчик создания за вычетом известной записи на час. Codex: модель берётся из `turn_context` на момент `token_count`; суммируется `last_token_usage`. Неизменившиеся общие счётчики и скопированные события исключаются. `cached_input_tokens` вычитается из `input_tokens`. События без модели показываются как `unattributed`, модель не угадывается.

Скрипт отражает только сохранённые локальные журналы. Он не восстанавливает удалённые события и не сверяет расход со счетами провайдера. Он не получает цены и не считает оплаченные подписки. Оценку API-эквивалента считайте отдельно по подтверждённым тарифам с явными допущениями о режимах и контексте. В таблицу сравнения включайте все модели с положительным расходом; `unattributed` требует проверки.

Содержимое диалогов, пути проектов и ключи не включаются в результат. Ничего не отправляется наружу. `reports/` исключён из Git; публикуйте агрегаты только по своему решению.

Проверка без доступа к реальным журналам:

```bash
python3 -m unittest discover -s tests -v
```
